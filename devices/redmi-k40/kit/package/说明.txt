Redmi K40 / POCO F3 (alioth) 上的 iOS 16 —— 一键内存启动包
================================================================

怎么用
------
1. 手机开机进 Android，打开 USB 调试，用数据线连电脑（Bootloader 需已解锁）。
2. 双击「启动.bat」。脚本会：确认是 alioth → 重启进 bootloader → 用 fastboot boot 把启动程序
   放进内存 → 传系统镜像（约 2.4 GB，USB 下大约 1.5 分钟）→ 传内核 → 启动 iOS。
3. 等桌面出现即可。想回 Android：重启手机（长按电源键，或电源 + 音量下强制重启）。
   注意：在 iOS 里选「重启」（或电脑用 iTunes 类工具让它重启）会回到启动程序的画面，不会直接回 Android，
   这时再长按电源键即可。

「启动-超广角.bat」「启动-微距.bat」：和「启动.bat」一样，只是相机 App 里的「后置摄像头」换成
超广角（IMX355）或微距（S5K5E9，定焦约 4 cm，拍很近的东西）。iPhone X 的相机 App 只有前后两颗，
所以每次启动选一颗当后置。

全程只在内存里运行：不刷写、不擦除手机上的任何分区，Android 系统和数据不受影响。
iOS 这边的数据盘也在内存里，每次启动都是全新的（设置、照片等不会保留）。

能用的（已在这台手机上逐项验证）
------------------------------
- 显示：120 Hz（面板 TE 8.2 ms），GPU 加速（Adreno 650，Mesa freedreno）；系统按 iPad 的
  默认帧率策略（80–120 Hz）渲染，不再被 iPhone 的 60–80 Hz 默认值卡住
- 亮度：控制中心 / 设置里的亮度滑块可调；开机默认亮度约为满亮度的 25%
- 自动亮度（设置 > 辅助功能 > 显示与文字大小 > 自动亮度，默认开）：光感（TCS3701，在传感器 DSP 上）
  的读数交给 iOS 自己的自动亮度曲线，遮住光感变暗、强光下变亮。iOS 调暗是故意慢慢来的（几秒到十几秒）；
  拖亮度滑块会让它学习你的偏好
- 自动旋转：照片、Safari 等支持横屏的 App 跟着手机转（竖屏、左右横屏；控制中心可锁定方向）
- 粗体文本（辅助功能）可以打开了，不再让桌面崩溃
- 反转颜色（经典 / 智能，智能反转时图片保持原色）、色彩滤镜（灰度、色调等）、夜览：都由显示硬件
  （DSPP 颜色校正）实现，和真 iPhone 一样；辅助触控（悬浮按钮）也能用
- 内存：12 GB 的 K40 给 iOS 11 GB（其余是固件和启动程序的；Android 自己也只看到 11.3 GB）。装好自带的
  应用后 iOS 还有约 5.5 GB 可用；数据盘（/private/var）跟着内存走，上限约 8 GB。6 GB / 8 GB 版本的 K40
  会自动用各自最大的一块内存（约 5 GB / 7 GB），这两种机器还没实测过
- 触摸、音量键、电源键、振动；长按侧边键不再弹出「打开 Siri」（没有 Siri，侧边键长按设为不做任何事）
- 声音：扬声器（CS35L41）、麦克风（语音备忘录可录音）。功放偶尔读数出错时会自动重新初始化，
  不再出现「玩到一半之后一直没声音」
- Wi-Fi：开机自动连接打包时写入的网络（5 GHz 优先），可上网
- 蓝牙：可被发现（名称 iPhone），可搜索、可配对；蓝牙音频可用：连上蓝牙音箱/耳机后 iOS 自动
  切到它播放（实测：把 Windows 电脑当蓝牙音箱，SBC 327 kbit/s，声音连续）
- 相机：「相机」App 实时预览和拍照（4032x3024，存进照片）。后置默认主摄（IMX582，4000x3000，自动对焦），前置 S5K3T2，
  可在 App 里前后切换；超广角 / 微距见上面的两个启动入口。每颗都按原厂调校做颜色校正
  （色彩矩阵、镜头阴影）
- 手电筒：控制中心的手电筒按钮
- 电池电量显示、充电
- 安装 IPA（不需要签名，IPA 要未加密）。两种办法：
  · 放进这个包的 apps 文件夹：每次启动时电脑通过局域网把它们装到手机上（见 apps\说明.txt）
  · 手机上的「IPA 安装」App：输入下载地址，或者在 Safari /「文件」里打开 .ipa →「共享」→「IPA 安装」
  实测：开源天气应用 OSS Weather 2.14.0 能装、能联网显示天气。手机重启后装的应用会消失
  （apps 文件夹里自带 GPU Check、Sensor Check、Motion Test 和 Map，组装时从它们的 GitHub Releases 下载，所以每次启动都会自动装上；
  从小到大依次装，几百 MB 的游戏最后装）
- Map（自带）：OpenStreetMap 地图，CPU 绘制（苹果地图要 Metal，已从系统里去掉）。拖动、双指缩放、
  定位蓝点和精度圈；右下角按钮依次切换 不跟随 / 跟随 / 跟随并显示朝向（真北）；顶上可以搜地名
- Sensor Check（自带）：一屏列出 App 能用到的所有传感器和硬件输入、实时数值和是否可用。
  在这台手机上：光线、运动、指南针、麦克风、摄像头、蓝牙、电池、120 Hz 都有数；气压计、计步、
  运动状态一直「等待数据」（K40 没有气压计，iOS 以为它是 iPhone X），距离传感器显示可用但不会变（还没驱动）
- 定位（Wi-Fi 定位，经苹果的定位服务）：开机自动打开「定位服务」，App 请求位置时照常弹授权框；
  实测 OSS Weather 用「当前位置」找到了所在的区。还没有 GPS，精度取决于周围的 Wi-Fi
- 运动传感器：加速度计、陀螺仪、姿态 / 重力都是真实数据（传感器 DSP），App 用 Core Motion 就能拿到。
  自带的 Motion Test 显示全部数值，上面有一个跟着手机转的 3D 手机模型（点它回到正对你的样子）
- 指南针：「指南针」App 显示朝向，随手机转动（先拿着手机画几个 8 字让磁力计校准）。App 有定位权限时
  给的是真北（按 NOAA 世界磁场模型 WMM2025 换算当地磁偏角），没有定位时是磁北
- 游戏和其他 OpenGL ES 应用：应用在自己的进程里用 GPU（Adreno 650，Mesa freedreno）画 OpenGL ES 1 / 2 / 3，
  画面和真 iPhone 一样交给系统合成。实测能玩：Minecraft PE 1.2.10（60 帧，建世界、走动）、Terraria 1.2
  （60 帧）、The Sims 3 Ambitions（OpenGL ES 1，62 帧）。每个应用有自己的 GPU 地址空间，一个应用读写不到
  别的应用和系统界面的显存（和真 iPhone 一样）。iPhone 的 GPU 才有的 PVRTC 压缩纹理由
  处理器解码；GLKit、SceneKit、SpriteKit、Core Image 在这类应用里也能用。游戏画面每秒最多 62 帧
  （iPhone X 是 60 Hz 屏，不限的话有的游戏会空转到每秒上千帧、点按钮没反应）
- Minecraft 1.2 在 iPhone X 上会把顶上一排（血量、饥饿、暂停）切掉一半，这是游戏自己的 bug（Mojang 的
  MCPE-30223，真 iPhone X 也一样）。这里让 Minecraft 自己看到的机型是 iPhone 8 Plus（同一颗 A11），界面就完整了
- GPU Check（自带）：一次跑完 83 项图形能力检查（OpenGL ES 1/2/3、各种纹理格式含 PVRTC、MSAA、GLKit、
  Core Image、SceneKit、SpriteKit、Metal、刷新率），每项显示通过 / 失败和原因。在这台手机上 81 项通过，
  剩下两项都是 Metal（没有 Metal 设备，预期之内；见下）

还不能用 / 已知问题
------------------
- 相机 App 里不能在主摄 / 超广角 / 微距之间直接切换（每次启动选一颗，见上）
- 手指滑动时约四分之三的帧是 120 Hz 节奏，其余多为 16 ms；剩下的主要是每帧的渲染开销
- 距离传感器、指纹、NFC、GPS、蜂窝网络：还没有驱动
- 没有 Metal（只有 OpenGL ES）：要 Metal 的 App 会打开就闪退，比如
  很多 3D 游戏（新版 Minecraft 也是 Metal）。界面、照片、Safari 这些不受影响
- GPU 卡死还不能自动恢复：一个应用让 GPU 卡住（比如着色器死循环），整机画面都会停，只能重启手机
- 游戏每次启动都会再问一次能不能发通知（数据盘在内存里，答案不保留）
- 辅助触控里的「主屏幕」点了没反应（悬浮按钮、菜单、控制中心都能用）
- 截图里看不到反转颜色 / 色彩滤镜 / 夜览的效果（它们在显示硬件里做，和真 iPhone 一样），屏幕上是对的
- 功耗：处理器和 GPU 都按负载自动调频（静止的主屏幕上小核 300 MHz、大核约 0.7–1 GHz、GPU 370 MHz，
  一碰屏幕立刻升满）；熄屏时面板进入睡眠、不再每秒刷新 120 次。实测（插着 USB）：亮屏静止少约 90 mA
  （约 38%）、Minecraft 少约 150 mA（约 33%），熄屏少约 180 mA，游戏帧率和滑动流畅度不变。
  GPU 熄屏后还没有完全断电，还在优化
- USB 连电脑：iOS 启动后电脑把手机认成一台 iPhone（需要电脑装有 iTunes / Apple Mobile Device Support），
  手机上弹出「要信任此电脑吗」时点「信任」。实测：用 pymobiledevice3 配对成功，能浏览 DCIM、下载等文件夹。
  iTunes、爱思助手之类还没逐个试过。Windows 资源管理器里看不到照片（相册导入用的接口还没做），
  配对每次启动都要重新信任（数据在内存里，不保存）
- 时间按组装这个包的电脑的时区显示

注意
----
- 这个包里有苹果的系统文件、手机厂商的固件，boot/run-payload.bin 里还有你的 Wi-Fi 名称和密码：只给自己用，不要转发。
- iOS 运行时拔掉 USB 线再插上：电脑十几秒后重新认出手机，信任过的配对在这次启动里继续有效。
  「要信任此电脑吗」在电脑上有程序要连手机时才会弹（比如打开 iTunes）
- 本包只支持 alioth（K40 / POCO F3）。
